
# Sales Data Analysis Dashboard — Excel

## Project Overview

This project analyzes business transaction data using Microsoft Excel. It includes a raw data sheet, PivotTables, and a dashboard with charts to explore revenue, expenses, profit, transaction volume, and business performance across product lines, regions, departments, customer segments, and payment methods.

## Dataset

- **Records:** 2,000 transactions
- **Columns:** 12
- **Date range:** January 1, 2022 – December 31, 2023
- **Missing values:** None found in the source data
- **Duplicate rows:** None found in the source data

### Columns

| Column | Description |
|---|---|
| `Transaction_ID` | Unique transaction identifier |
| `Transaction_Date` | Date of transaction |
| `Revenue` | Revenue generated by the transaction |
| `Expenses` | Expenses associated with the transaction |
| `Profit` | Profit recorded for the transaction |
| `Category` | Business category |
| `Region` | Geographic region |
| `Department` | Department associated with the transaction |
| `Product_Line` | Product line |
| `Customer_Segment` | Customer segment |
| `Payment_Method` | Payment method used |
| `Discount` | Discount applied |

## Tools & Excel Features

- Microsoft Excel
- PivotTables and PivotCharts
- Dashboard charts
- Filterable PivotTable analysis

## Dashboard & Analysis

The workbook contains a `Dashboard` sheet and five PivotTable analysis sheets.

The analyses cover:

1. **Profit by Payment Method** — compares total profit from Cash, Credit Card, Bank Transfer, and PayPal.
2. **Revenue by Product Line** — compares revenue across Clothing, Electronics, Furniture, Healthcare, and Software.
3. **Department Performance** — compares revenue, expenses, and profit by department.
4. **Transaction Count by Region** — compares transaction volume across regions.
5. **Average Expenses by Department** — compares average expenses across departments.

The workbook also includes a filter-oriented sheet with fields such as Customer Segment and Department for exploring PivotTable results.

### Additional Insights

- **Top product line by revenue:** Healthcare — 21,863,582.
- **Top region by transaction count:** Africa — 818 transactions.
- **Top payment method by total profit:** Cash — 9,013,666.
- **Top category by total profit:** R&D — 8,330,376.
- **Top customer segment by revenue:** SMB — 22,818,233.
- **Yearly profit:** 2023 recorded 10,472,825 profit compared with 10,020,704 in 2022.

These are descriptive findings from this dataset and do not, by themselves, establish why a category or region performed better.

## How to Use

1. Download `sales data excel dashboard.xlsx` from this repository.
2. Open the workbook in Microsoft Excel.
3. Go to the `Dashboard` sheet to view the dashboard.
4. Review the `pivot 1` through `pivot 5` sheets for supporting summaries.
5. Use the available PivotTable filters to explore different segments.
